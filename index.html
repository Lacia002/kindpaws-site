KindPaws KIND

Kindness for every paw.

让善意可追踪、让参与可轻量、让救助可复盘。 我们把「想帮忙」的人，和「正在帮」的人连起来——用轻量、透明、低摩擦的方式，支持流浪猫狗的伤病救治、绝育、临时寄养、转运与基本物资。

KIND 部署于 Solana；模式为自愿众筹 + 贡献导向空投。代币是社区参与与治理信号，不是理财产品——无保本、无 APY、无「买入即暴富」。

请先读清这几条

  • 链与模式：KIND 在 Solana；自愿众筹 + 贡献空投；默认救助对象为流浪猫、流浪狗。
  • KIND 定位：效用与参与/治理信号代币——标识支持者、激励核验贡献、对救助提案做轻量投票信号；不是证券化收益产品，不是理财，无本金保障、无稳定收益、无 APY / 被动收入承诺。
  • 边界：持有或购买 KIND ≠ 捐赠收据 ≠ 税务抵扣凭证 ≠ 对某一具体救助个案的合同义务或结果保证。
  • 叙事：强调资金与救助透明公示；反对「买入即暴富 / 买入即空投暴富」的投机叙事。

项目机制

选择轻量链上工具，是为了降低协调成本、提高参与与公示效率——把钱尽量花在猫狗身上，而不是复杂玩法上。 总量 10 亿 KIND、六桶分配比例，以及众筹现金 60% 救助国库 / 40% 项目完善（多签+公示）已按白皮书 v0.1.1 公开； 窗口、硬顶、发放公式、合约地址等仍为草案 / 待公布，以正式「参与须知」为准。

自愿众筹

在明确时间窗与硬顶（额度待公布）内，筹集可公示的启动与救助资金。用途类别事先说明、事后复盘；参与自愿，不保证正收益或特定救助结果。

🎁

贡献空投

KIND 侧重奖励核验后的真实贡献：实地救助、寄养、医疗对接、内容、志愿运营、早期建设等。多轮可调；空投不等于投资回报，也不是「买入门槛暴富」。

🔗

Solana · 低摩擦

选 Solana 是为了手续费可控，便于小额互动与空投分发。合约地址部署后公示；上线前本站不提供可转账地址。

🏠

默认救助对象

默认：流浪猫、流浪狗（伤病救治、绝育、临时寄养、转运、基本物资等）。具备条件时可与备案/正规机构协作并单独公示；不承诺每一笔立刻对应某一只动物的成功结局。

KIND 计划中的效用（草案）

  • 社区参与凭证（身份、徽章、贡献者名录等，以可核验为准）
  • 救助提案的轻量投票 / 优先级信号（信号 ≠ 必然执行的硬承诺）
  • 经核验贡献的致谢与激励（不是工资替代，也不是收益权）
  • 品牌与活动类用途（分享会、周边优先、领养日志愿档等，规则单独公示）

权重与上线节奏可调整；若未来有锁仓等技术功能，目的限于参与资格、反滥用或治理权重，而非收益承诺。

透明公示（信任基础）

计划公开：C_treasury / C_ops 接收安排与多签成员阈值、收入（含众筹总额 C 及 60/40 入账）与分列支出明细、救助案例卡片（含失败与遗憾）、空投摘要与合约/权限变更。 轻量流程草案：提案 → 复审/信号 → 拨付 → 回执 → 月度看板。频率建议至少每月一次，重大支出即时——正式节奏待公布。 公示文案不得将「60% 现金进入救助国库」写成「投资者获得 60% 代币」。

众筹现金用途（已拍板 · 多签公示）

设众筹实际募得现金（或等值）为 C。现金按下列比例拆分，与 KIND 代币分配比例无关：

  • 救助国库 C_treasury = 60%（0.6C） — 直接救助相关支出（医疗、绝育、物资、寄养补贴、转运等）及经公示的救助应急；多签 + 公示
  • 项目完善 C_ops = 40%（0.4C） — 官网、工具、审计、必要合规与透明看板等；多签 + 公示

两科目应可区分记账；支出进透明看板；未使用余额滚动并公示。C_ops 不得挪作未公示的私人开支。

重要：现金拆分 ≠ 众筹代币发放

60% / 40% 是「现金 C」的拆分，不是「众筹桶 25% KIND」的发放比例，也不是「出资占比 = 得币占比」的自动公式。 现金轨（救助国库 / 项目完善）与代币轨（众筹桶 25% KIND 如何发给参与者）是两套并行规则——勿混用百分比。 众筹桶发放细则待「参与须知」单列公示；出钱是支持救助与启动，得代币是参与凭证，不是理财收益。

众筹窗口、硬顶、单人上下限、接受资产、超额处理、多签成员/阈值等仍待公布。

路线图

务实原则：先跑通「小额救助 + 公示 + 小范围空投」，再谈规模化。时间点为草案，以实际交付与官方公告为准。

  1. 阶段 0 · 准备（约 4–8 周 · 草案）

    品牌、规则与最小透明看板

    完成叙事与白皮书社区讨论；落实已拍板参数（总量 10 亿、六桶比例、现金 60/40）；补齐多签成员、C_treasury / C_ops 地址、众筹桶发放公式与空投计分细则（待公布）；部署 KIND（Solana）并公示合约；上线分列救助国库与项目完善支出 + 案例的最小看板；合规基线审阅（地区与表述待定）。

  2. 阶段 1 · 试点（约 1–3 个月 · 草案）

    小额硬顶众筹与首批可公示救助

    小额硬顶众筹；完成首批可核验救助案例或绝育批次（数量目标待定）；创世贡献空投第 1 轮快照与领取；收集滥用与规则漏洞并修订。

  3. 阶段 2 · 机制打磨（约 3–6 个月 · 草案）

    提案信号、月报与机构试点

    救助提案投票/信号 v1；贡献者徽章（非金融收益）；固定月度透明报告；探索 1–2 家正规合作机构试点；活动门票类用途小范围试验。

  4. 阶段 3 · 扩展（6 个月以后 · 草案）

    多协作网络与稳态空投

    多城市/多机构协作（仍以可核验为先）；里程碑驱动的空投轮次；视需要引入有限审计与更好看板；评估是否并行「法币正规捐赠通道」（与 KIND 持有脱钩说明）。

近期明确非目标：复杂杠杆与高收益农场、无法核验的「巨量救助」口号、用价格预测或喊盘代替救助进度。
